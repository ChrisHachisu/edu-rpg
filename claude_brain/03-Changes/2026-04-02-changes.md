# Change Log — 2026-04-02

**Session:** [[2026-04-02]]
**Commits:** `60ec968` (main), `f91f5de` (gh-pages)
**Summary:** Restored the V3 world expansion (320×400) and portal dungeon mechanics that had been deployed to gh-pages but never committed to main.

---

## src/data/maps.ts

**Reason:** Overworld size and all map coordinates were out of date. Source had regressed to 120×160 while gh-pages bundle proved 320×400 was the intended state.

- Overworld `width`: 120 → 320, `height`: 160 → 400
- All map entrance/exit coordinates recalculated for new world layout
- Added towns: `frostwatch`, `hauntedVillage`
- Added dungeons: `whisperingWoodsCave`, `coastalReef`, `ironMine`, `hauntedForest`, `scorchedRuins`, `emberMines`, `obsidianCavern`, `demonBarracks`, `voidRift`
- Portal dungeon sizes: updated to 100×100, 6 floors, with `mechanic` property
  - `frostfallCavern` → mechanic: `'ice'`
  - `stormreachSpire` → mechanic: `'wind-tower'`
  - `sunkenTempleDungeon` → mechanic: `'maze-hunter'`
  - `twilightDungeon` → mechanic: `'shadow-portal'`

---

## src/utils/MapGenerator.ts

**Reason:** Overworld generator needed to produce a 320×400 map with 4-quadrant elliptical landmasses. Three new dungeon mechanics required generation logic.

- Replaced overworld generator function with 320×400 version
- Added mechanic: `wind-tower` — places tile 25 (wind corridors) along main path
- Added mechanic: `shadow-portal` — places tile 29 (portal pairs) at path midpoints
- Added mechanic: `maze-hunter` — generates perfect maze via recursive backtracker
- Extended `DungeonMapResult` type: added `windCorridorDir`, `portalPairs`, `goldenChestPos` fields

---

## src/scenes/WorldMapScene.ts

**Reason:** Runtime logic for the three new dungeon mechanics needed to be wired into the scene update loop.

- Added `updateWindTower()` and `handleWindPush()`: 4s calm / 2s gust cycle that pushes the player
- Added `updateMazeHunter()`: BFS pathfinding, line-of-sight detection, hunter enemy + boss spawn
- Added shadow portal step handler: fade-out → teleport to pair → fade-in transition
- Added new instance variables for all mechanic states

---

## src/utils/AssetGenerator.ts

**Reason:** Two new tile types referenced by the portal mechanics had no visual definitions.

- Added tile 25: wind-corridor (arrow pattern on floor tile)
- Added tile 29: shadow-portal (dark swirling pool tile)
