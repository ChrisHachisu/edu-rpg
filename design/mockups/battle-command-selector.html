Flagged while building this

1. Parchment colours still hardcoded. battlePlayerBar() paints the name line #fdf3da and the HP number #ffeac0, and the enemy card paints its name #ffd9a6 with a red gradient HP fill. All four predate Charcoal and Gold Leaf. Use the "Parchment colours" switch above to see them swapped for --ink, --gold and --ruby. The switch is not part of any variant, it applies to all three.

2. The shield glyph cannot be tinted. qok-shieldw hardcodes fill="#fff", which only worked because it sat on a saturated blue block. Every variant here needs a currentColor version, added as qok-shieldc.

3. GAME-FEEL.md has no token for selection travel. The nearest is micro.transition at 200ms, written for popups and dialogs. A menu cursor at 200ms reads sluggish. Nothing was invented here: the header offers 200ms and a 120ms candidate so the choice is yours, and whichever wins should become a real token before implementation.
